# AltAltAgent

画面の一部を撮影して、マークや文字を書き込み、**CodexやChatGPTなどのAIエージェントの入力欄へそのまま貼り付ける** Windows 用の小さなアプリです。

「ここのボタンの色を変えたい」「この表示がおかしい」といったことを、言葉だけで説明するかわりに、画面を丸で囲んで見せるために作りました。

### [⬇ 最新版をダウンロード（AltAltAgent.exe）](https://github.com/nyokinyokicompany/AltAltAgent-releases/releases/latest/download/AltAltAgent.exe)

インストールは不要です。ダウンロードして、ダブルクリックするだけで使えます。

> このリポジトリは**配布専用**です。実行ファイル（`AltAltAgent.exe`）と説明だけを置いています。

> このアプリは、**AIと相談しながらコードを書く「バイブコーディング」**で作りました。自動テストと実際の画面での確認はしていますが、すべての環境で確かめられているわけではありません。不具合があるかもしれないので、大事な作業の前には試してからお使いください。

## どんなアプリ

ふだんは Windows の右下（通知領域）に常駐していて、ショートカットを押したときだけ働きます。

1. ショートカットを押して、画面の範囲を選ぶ
2. 丸・四角・矢印・自由線・文字で説明を書き込む
3. 「貼り付け」を押すと、AIの入力欄に画像が貼り付く

- **操作が少ない**: 撮影から貼り付けまで、マウスと Enter だけで終わります。
- **メッセージは自動で送りません**: 貼り付けるだけです。送信は自分で行います。
- **API を使いません**: 追加の料金はかかりません。
- **5つの言語**: 日本語・English・简体中文・繁體中文・한국어

## ダウンロードと起動

1. [ここをクリック](https://github.com/nyokinyokicompany/AltAltAgent-releases/releases/latest/download/AltAltAgent.exe)して `AltAltAgent.exe` をダウンロードします。
2. 好きなフォルダーに置きます（例：ドキュメントの中）。
3. ダブルクリックで起動します。右下に「起動しました」と表示されます。

**置き場所のおすすめ**: 自分で書き込めるフォルダー（ドキュメントなど）に置いてください。`C:\Program Files` の中だと、あとで「更新を確認…」が失敗します。

**右下のアイコンが見えないとき**: 右下の `^` を押すと、隠れているアイコンが出てきます。アイコンをタスクバーへドラッグすると、いつも見える状態にできます。

### 初回の警告について

初めて起動するとき、「WindowsによってPCが保護されました」と表示されることがあります。このアプリには、有料の署名（配布元の証明）を付けていないためです。

「**詳細情報**」→「**実行**」を押すと起動できます。

### ダウンロードしたファイルを確認したい方へ

ダウンロードしたファイルが、公開したものと同じか確認できます。

1. ダウンロードしたフォルダーで、スタートボタンを右クリックして「ターミナル」を開きます。
2. 次を入力して Enter を押します。

```
Get-FileHash .\AltAltAgent.exe -Algorithm SHA256
```

3. 表示された文字列が、[Releases](https://github.com/nyokinyokicompany/AltAltAgent-releases/releases/latest) の `AltAltAgent.exe` の横にある `sha256:` のあとの文字列と同じなら、同じファイルです（大文字・小文字の違いは気にしなくて大丈夫です）。

## 基本の使い方

1. AIエージェントの**入力欄をクリック**します（貼り付け先になります）。
2. **ショートカットを押します**。標準は「**左右の Alt キーを同時に 0.3 秒押し続ける**」です。
3. Windows 標準の切り取り画面が出るので、**撮影したい範囲をドラッグ**します。
4. 編集画面が開くので、**マークや文字を書き込みます**。
5. **「貼り付け [Enter]」を押す**（または Enter キー）と、さきほどの入力欄に貼り付きます。

途中でやめたいときは `Esc` キーです。切り取り画面を `Esc` で閉じた場合は、すぐに撮り直せます。

> **ご注意**: 撮影すると、クリップボード（コピーしたもの）の中身が撮影した画像に置き換わります。

### 書き込みをしたくないとき

右下のアイコンを右クリックして「設定…」を開き、「撮影後にマークを書き込む」をオフにします。範囲を選んだだけで、すぐに貼り付きます。

## 書き込みの機能

| 機能 | 説明 |
| --- | --- |
| 自由線 | マウスで好きな線を描きます |
| 四角・丸 | ドラッグで囲みます |
| 矢印 | ドラッグした向きに矢印を描きます |
| 文字 | 「文字」を選び、画像をクリックして入力します。**Enter で確定**、Shift＋Enter で改行します |
| 消しゴム | 書き込みだけを消します（元の撮影画像は消えません） |
| 色 | ピンク・黄・緑・青・濃紺・白 |
| 線・文字サイズ | 細・普通・太 |
| 戻す | `Ctrl`＋`Z`（または「戻す」ボタン） |
| 全部消す | 「全消去」ボタン |
| 拡大・縮小 | `Ctrl`＋マウスホイール、または「＋」「－」ボタン |
| 全体表示 | `Ctrl`＋`0` |
| 貼り付け | `Enter` |
| やめる | `Esc` |

## 縦に長いページを丸ごと貼る

画面に入りきらない長いページや PDF も、1枚の縦長の画像にして貼り付けられます。

1. いつものように撮影して、編集画面を開きます。
2. 「貼り付け」の横の「**スクロール全体を貼り付け**」を押します。
3. 撮りたい**本文をクリック**します。横の一覧などを除きたいときは、ドラッグで横幅だけ指定します（上下は自動で最上部から最下部まで撮影します）。
4. 自動でスクロールしながら撮影して、つなぎ合わせ、貼り付けます。撮影元のスクロール位置も元に戻します。

**うまく使うコツ**

- PDF は「連続スクロール」の表示にしてください。
- 撮影中は、対象の画面を動かしたり、ほかのウィンドウで隠したりしないでください。`Esc` で中止できます。
- 画像のつなぎ目を確認できなかったときは、途中までの画像を「全体」として貼らずに止まります。
- 撮影できる大きさは、高さ 30,000 ピクセル・3,200 万画素・200 回・2 分までです。
- Windows にスクロール位置を教えてくれるアプリが対象です。対応していない場所では、そう表示されます。
- 元の画像に書き込んだマークは、新しく撮った画像には入りません。

## 別のPCのAIへ貼る

リモートデスクトップ（RDP）でつないだ**別のPCのAI**へ画像を渡すための機能です。2台の PC のどちらからどちらへも使えます。

**準備（最初の1回だけ）**

1. 2台の PC の**両方**に、同じ `AltAltAgent.exe`（バージョン 1.2.0 以降）を入れます。
2. 操作する側の PC で「リモート デスクトップ接続」を開き、「**オプションの表示**」→「**ローカル リソース**」→「**クリップボード**」をオンにしてから接続します。接続中に変えたときは、つなぎ直してください。

**使い方**

1. 撮影したい側の PC で、右下のアイコンを右クリックして「**別PC用に撮影…**」を選びます。
2. 範囲を選び、書き込んだら「**別PC用にコピー [Enter]**」を押します。
3. もう一方の PC に切り替えて、AIの入力欄をクリックし、`Ctrl`＋`V` で貼り付けます。

通常の編集画面にある「別PCへ」のメニューからも、同じようにコピーできます。縦長の画像は「スクロール全体をコピー」を使います。

**ご注意**

- 会社などの設定で、RDP の画像の共有が禁止されている場合は使えません。
- コピーしてから少し待って貼り付けてください。貼り付けが終わるまで、別のものをコピーしないでください。
- 貼り付けられないときは、まず短い文字をコピーして、相手の PC に貼れるか試してください。文字も渡らないときは、RDP のクリップボード設定を確認します。

## 設定

右下のアイコンをダブルクリックするか、右クリックして「設定…」を選びます。

| 項目 | 内容 |
| --- | --- |
| 撮影ショートカット | 左右 Alt／Print Screen／`Ctrl`＋`Shift`＋`S`／F8／F9 から選べます |
| 撮影後にマークを書き込む | オフにすると、撮影してすぐ貼り付けます |
| Windows起動時に自動起動 | オンにすると、PC を起動したときに常駐を始めます |
| 表示言語 | Windows に合わせる／日本語／English／简体中文／繁體中文／한국어 |
| 画面の大きさ | 設定画面で `Ctrl`＋マウスホイール、または `Ctrl`＋`＋`／`Ctrl`＋`－` でも変えられます |

> **リモートデスクトップ（RDP）で使うとき**: 左右 Alt の同時押しは、リモートの画面には届きません。**F8・F9・`Ctrl`＋`Shift`＋`S`** のどれかに変えてください。

右下のアイコンを右クリックすると、「別PC用に撮影…」「使い方」「更新を確認…」「設定…」「終了」が選べます。

## 更新

バージョン 1.3.0 以降は、アプリの中から最新版に更新できます。

1. 右下のアイコンを右クリックして「**更新を確認…**」を選びます。
2. 新しい版があれば、確認の画面が出ます。「はい」を押します。
3. 自動でダウンロードして入れ替え、アプリが再起動します。設定はそのまま引き継がれます。

- 撮影・編集・設定の途中では更新できません。終わってから押してください。
- ダウンロードしたファイルは、公開されたものと同じか確認してから入れ替えます。確認できなかったときは入れ替えず、今までの版のまま使えます。
- 1.2.0 以前のバージョンには、この機能がありません。最新版を一度ダウンロードしてください。

今までの更新内容は [Releases](https://github.com/nyokinyokicompany/AltAltAgent-releases/releases) で見られます。

## 困ったとき

**ショートカットを押しても撮影が始まらない**

- すでに起動しているか、右下のアイコンを確認してください。
- リモートデスクトップの中では、左右 Alt は使えません。F8 などに変えてください。
- 管理者として実行しているアプリの上では、反応しないことがあります。
- 設定でショートカットを別のキーに変えてみてください。

**貼り付けが入力欄に入らない**

- 画像の貼り付け（`Ctrl`＋`V`）に対応した入力欄かどうか、確認してください。サービスによっては、画像を貼れない画面があります。
- 「貼り付け先に戻れませんでした」と出たときは、画像はコピーできています。入力欄をクリックして、`Ctrl`＋`V` を押してください。

**「この場所の縦スクロールを操作できません」と出る**

- PDF は連続スクロールの表示にして、本文の部分をクリックしてください。
- アプリによっては、スクロール位置を Windows に教えない場合があり、その場合は使えません。

**「すでに起動しています」と出る**

- 右下に常駐しています。アイコンを確認してください（`^` の中に隠れていることがあります）。

**更新に失敗する**

- 書き込みできない場所（`C:\Program Files` など）に置いていると失敗します。ドキュメントなど、書き込めるフォルダーへ移してください。

## プライバシーと通信

- 撮影した画像は、**あなたの PC の中だけ**で処理します。ファイルとして保存したり、インターネットへ送ったりしません。
- 画像は Windows のクリップボードへコピーされます。コピー内容は、次に何かコピーするまで残ります。
- アプリがインターネットにつなぐのは、**「更新を確認…」を押したときだけ**です。つなぎ先はこの GitHub のリポジトリで、個人の情報は送りません。
- 利用状況の収集は行っていません。

## 動作環境と確認状況

- **対応**: Windows 10 / 11（64bit）。.NET などの追加インストールは不要です。
- **使うもの**: Windows 標準の画面の切り取り機能（`Windows`＋`Shift`＋`S`）。アプリが呼び出して使います。
- **確認済み**: Windows 11、Chrome・Edge の通常のページ、Chrome の PDF ビューアーでのスクロール撮影、別PC用のコピー（同じ PC 内でのクリップボードの受け渡し）。
- **十分に確認できていない環境**: 表示倍率の異なる複数のモニター、Chrome 以外の PDF ビューアー、実際の 2 台の PC 間での RDP の転送。

## アンインストール

1. 設定で「Windows起動時に自動起動」をオフにします（オンにしていた場合）。
2. 右下のアイコンを右クリックして「終了」を選びます。
3. `AltAltAgent.exe` を削除します。

設定は Windows のレジストリ（`HKEY_CURRENT_USER\Software\AltAltScreenshot`）に少しだけ残ります。気になる場合は、レジストリエディターで削除できます。
